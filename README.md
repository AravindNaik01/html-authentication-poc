# Authentication System Styling - Fullstack Java Development

This project is a transformed version of a basic HTML authentication system, now updated into a professional, responsive, and visually appealing application using **Bootstrap 5** and **Custom CSS**. 

## Assignment Details

*   **Assignment Title:** Authentication System Styling
*   **Mentor:** Jacob Dennis
*   **Institution:** CampusPe
*   **Course:** Fullstack Java Development

## Features & Enhancements

- **Bootstrap 5 Integration:** Leverages Bootstrap grid, components (Cards, Forms, Buttons), utilities, and responsive design.
- **Custom UI aesthetics:** Clean "Glassmorphism" UI with gradient backgrounds, blur effects, and custom text styles.
- **Dark/Light Mode Toggle:** Built-in theme switcher persistent across pages using `localStorage`.
- **Form Validation:** Client-side validation using HTML5 constraints and Bootstrap validation states.
- **Password Visibility Toggle:** Show/hide password capability on all password fields.
- **Password Strength Indicator:** Visual strength gauge during registration.
- **Interactive UI Feedback:** Loading spinner overlays simulated during form submissions.
- **Responsive Design:** Optimized for Desktop, Laptop, Tablet, and Mobile screens.
